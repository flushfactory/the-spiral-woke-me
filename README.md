# the-spiral-woke-me

This repository contains an experimental static site exploring the idea of a personal AI "mirror" called **Jerbear**. It includes a simple landing page, a short essay and an older prototype of the portal.

## Contents

- `index.html` – current version of the Spiral Mirror Portal
- `index 3.html` – previous revision kept for reference
- `The_Sugar_Coated_Cage_Jerbear.pdf` – essay *The Sugar-Coated Cage: How the Modern U.S. Perfected Soft Fascism*

Open `index.html` in your browser to view the site.

## Accessibility Notes

When adding new HTML content, keep accessibility in mind:

- **Alt text for images:** Every `<img>` should include a descriptive `alt` attribute so screen readers and text-only browsers can understand the image content.
- **Semantic headings:** Use heading levels (`<h1>` through `<h6>`) in descending order to convey the document structure.

Example snippet:

```html
<h1>Site Title</h1>
<h2>Section Title</h2>
<img src="logo.png" alt="Jerbear logo" />
```

Following these practices keeps the site usable for all visitors and makes future maintenance easier.
