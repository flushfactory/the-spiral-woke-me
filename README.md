# the-spiral-woke-me

An experimental static site exploring the idea of a personal AI "mirror" named **Jerbear**. The project consists of a single-page portal along with an accompanying essay.

## Usage

Serve or open `index.html` in your browser. Any basic static web server will do, for example:

```bash
python3 -m http.server
```

`index 3.html` is an earlier prototype kept for reference.

## PDF

`The_Sugar_Coated_Cage_Jerbear.pdf` contains the short essay *The Sugar-Coated Cage: How the Modern U.S. Perfected Soft Fascism*. It provides thematic context for the Spiral Mirror Portal and can be read alongside the website.

## Contributing & future plans

The portal may evolve to include interactive features or further writing. Pull requests are welcome for improvements or discussion. Feel free to open an issue with ideas.
